# Мастерская решений — 1.1.0

Интерактивный учебный курс по математике, моделям, прогнозам и проверке решений. Полный статический проект для GitHub Pages: исходники одновременно являются файлами сайта. Установка пакетов, сборка, ключи API и серверная база для работы курса не нужны.

## Размещение на GitHub Pages

Распакуйте архив. Загрузите **его содержимое**, а не сам ZIP, в корень нового репозитория. На верхнем уровне должны находиться `index.html`, `.nojekyll`, папки `assets` и `js`; остальные файлы документации и тестов можно загрузить вместе с ними. Не помещайте весь сайт в дополнительную папку, если собираетесь публиковать из корня.

Откройте **Settings → Pages → Build and deployment**. В поле **Source** выберите **Deploy from a branch**. Укажите ветку **main** (либо свою фактическую ветку) и папку **/(root)**, затем **Save**. Ветка должна уже содержать загруженные файлы.

Адрес сайта появится в разделе Pages после завершения развёртывания. Сайт использует относительные пути к ресурсам и маршруты после `#`, поэтому название репозитория менять в коде не требуется. Файл `.nojekyll` включён в комплект; при загрузке с компьютера убедитесь, что скрытые файлы также попали в репозиторий.

Официальная инструкция GitHub, проверенная при подготовке этой версии:
https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

Репозиторий и опубликованный сайт не создаются автоматически вместе с архивом.

## Запуск на компьютере

Можно открыть `index.html` в современном браузере, сохраняя рядом папки `assets` и `js`. Если политика браузера ограничивает работу локальных файлов, запустите из папки проекта обычный статический сервер:

```sh
python3 -m http.server 8000
```

В Windows с установленным Python команда может называться `python` вместо `python3`. Затем откройте `http://localhost:8000`.

## Состав курса

В этой версии 24 модуля, объединённых в шесть ступеней, и 144 урока. Каждый урок содержит дополнительное объяснение, разобранный пример, вопрос для объяснения своими словами и три задания: повторение способа, новое условие и отдельную самопроверку. Всего 432 обычных задания. Ещё 42 проверяемых шага находятся в 24 итоговых миссиях.

41 лаборатория позволяет взаимодействовать с числами, группами, процентами, матрицами, распределениями, графами, прогнозами, ресурсами, календарём и историями работ. Встроенная лаборатория получает контекст урока и открывается в соответствующем режиме. Во многих лабораториях доступны дополнительные режимы исследования.

Глоссарий содержит 227 понятий. Библиография включает 27 источников и ориентиров, в том числе предметные источники по математике, оцениванию прогнозов и анализу сетей. Ссылки на методические материалы не являются доказательством образовательной эффективности самого курса.

Итоговая мастерская T41 — связанный учебный проект: пять структурированных проверяемых частей и письменное заключение. Заключение можно явно выгрузить в текстовый файл. Его смысл программа не оценивает: рядом приведены вопросы для самопроверки или обсуждения с преподавателем.

## Как устроено оценивание

Задания A и B предназначены для тренировки. Задание C использует новый пример для самопроверки. Завершение урока требует выполнения всех трёх заданий. Отметка отдельно сообщает, выполнен ли новый вариант с первой проверки без раскрытия помощи либо после помощи или исправлений. Это описание действий в текущем сеансе, а не сертификат владения темой.

Открытие подсказки или разбора отмечается как помощь. Обратная связь содержит шаги решения; для ряда характерных ошибок предусмотрено адресное пояснение. В заданиях с отдельным полем основания числовой ответ без верного основания не принимается. Свободный текст по ключевым словам не оценивается.

Смешанная практика использует собственное состояние попытки. Предыдущие ответы в уроках не засчитываются за повторную практику. В результате раздельно показываются выполненные задания, задания с проверкой ответа, пропуски, помощь и ответы с первой проверки. Повторный запуск практики создаёт новый результат.

Вопросы «Да/Нет», создававшие систематическую возможность угадывать отрицание, заменены содержательными альтернативами. Порядок вариантов отображается в перемешанном виде; позиция правильного ответа в массиве данных не определяет его позицию на экране.

## Приватность и сохранение

Регистрации, учётных записей, рекламы и аналитических счётчиков нет. Приложение не записывает ответы в cookies, localStorage, sessionStorage или серверную базу. Ответы, заметки, состояние лабораторий и текущая практика находятся только в памяти открытой страницы и исчезают после её перезагрузки или закрытия.

Исключение — только явное нажатие кнопки экспорта заключения в T41: браузер создаёт локальный `.txt`-файл на устройстве пользователя. Этот файл не отправляется на сервер. Внешние источники открываются по нажатию пользователя. Обычные запросы браузера к хостингу для загрузки файлов сайта не являются отправкой ответов приложения.

Озвучивание использует доступный локальный русский голос браузера или операционной системы. Собственной дикторской записи и обращения приложения к облачному синтезу речи нет.

## Устройство проекта

| Файл | Назначение |
|---|---|
| `index.html` | Точка входа; порядок подключения скриптов имеет значение. |
| `assets/styles.css` | Оформление, мобильные размеры, фокус, печать. |
| `assets/favicon.svg` | Векторный знак приложения. |
| `js/content.js` | Полное содержимое курса: уроки, объяснения, задания, источники, маршрутизация лабораторий. |
| `js/engine.js` | Базовые математические функции и инспектор событий. |
| `js/learning-engine.js` | Дополнительные вычисления, проверка основания, независимая статистика практики. |
| `js/helpers.js` | Общие элементы интерфейса, поиск, форматирование и память сеанса. |
| `js/tasks.js` | Поля ответа, обратная связь, подсказки и проверка заданий. |
| `js/labs.js` | Исходные лаборатории с точечными исправлениями. |
| `js/labs-learning.js` | Новые лаборатории T30–T41, предметные режимы и итоговый проект. |
| `js/learning-ui.js` | Разобранные примеры, заметки, предварительные знания и статусы уроков. |
| `js/app.js` | Страницы, навигация, сеанс и повторная практика. |
| `js/icons.js` | Встроенные векторные значки. |
| `tests/*.test.cjs` | Автоматические проверки на встроенном тестовом модуле Node.js. |

Внешних JavaScript-библиотек и удалённо загружаемых шрифтов нет. Не требуется установка React, Vite или других средств сборки. Файл `package.json` нужен только для удобного запуска тестов и локального сервера.

Для редактирования содержания изменяйте согласованно условие задания, `check`, `answer`, `steps`, подсказку и, при наличии, `reasoning`. Поля `guide` содержат дополнительное объяснение; `prerequisite` — ссылку на опорную тему; `interactive` и `labMode` задают лабораторию и режим. Не переименовывайте идентификаторы без изменения связанных ссылок.

## Проверки разработчиком

При установленном Node.js 22 или новее:

```sh
npm test
```

Установка зависимостей не требуется. В выпуске 505 автоматических тестов. Среди них есть проверки схем ответов и связности содержания, а также независимые числовые контрольные случаи. Проверка схемы ответа не равнозначна независимому доказательству математической корректности самого ключа.

Сведения о браузерных проверках, исправленных регрессиях и ограничениях испытаний находятся в `QA.md`. Изменения относительно исходного архива описаны в `CHANGELOG.md`.

## Область применения

Курс предназначен для введения в понятия, тренировки отдельных действий и сопровождаемого преподавателем обсуждения. Сложные методы показаны на небольших учебных моделях. Например, локальное улучшение разбиения графа не представляется полной реализацией алгоритма Лувена, а ограничение экспертного веса прямо обозначено как учебное правило, а не универсально оптимальная оценка.

Все числовые ситуации учебные. Успешные программные проверки не доказывают прирост знаний, устойчивое владение методом или доступность всех тем человеку с нулевой подготовкой. Исследование на учащихся, независимая содержательная экспертиза и полная проверка доступности остаются отдельными задачами.
