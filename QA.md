# Проверка выпуска 1.1.0

Дата подготовки: 17 сентября 2026 года. Объект проверки — файлы настоящего полного выпуска, а не опубликованный сайт.

## Автоматические проверки

Команда `npm test` завершилась успешно: **505 тестов, 505 пройдено, 0 ошибок и 0 пропусков**. Синтаксис всех JavaScript-файлов дополнительно проверен командой `node --check`.

474 проверки относятся к схемам ответов обычных заданий и шагов миссий. Они проверяют, что предусмотренный ответ принимается, а альтернативный тестовый ответ отвергается; они не заменяют независимую экспертизу содержания каждого условия и ключа. Другие проверки охватывают вычислительные контрольные случаи, числовые границы, ссылки между материалами, предварительные знания, новые поля учебного содержания и отсутствие механизмов постоянного хранения ответов.

Для новых вычислений предусмотрены независимые примеры нормальной вероятности, логарифма и обратного преобразования, решения и вырожденности системы, спектрального радиуса, PageRank, посредничества, модульности, ARI и изоляции результатов повторной практики.

## Браузерная среда

Использованы Chromium и Playwright. Специализированный Browser-плагин в среде отсутствовал. Прямой переход браузера к локальному HTTP-адресу был заблокирован политикой среды (`ERR_BLOCKED_BY_ADMINISTRATOR`). Поэтому исходные HTML, CSS и JavaScript подключались непосредственно к браузерному документу в штатном порядке, без подмены логики приложения.

Это позволяет проверять отрисовку, события, DOM, вычисления и состояние приложения, но **не является проверкой сетевого развёртывания на GitHub Pages**. Относительные пути и полнота файлов контролировались отдельно. Скриншоты финальных состояний делались после завершения прокрутки; для стабильного захвата включалась поддерживаемая приложением настройка уменьшенного движения.

## Воспроизведённые учебные сценарии

Сначала всем заданиям в основной памяти был присвоен прежний успешный результат. Затем начата новая практика и пропущены все восемь заданий. Получен результат **0 из 8**, а не прежние 8 из 8. Следующий заход показывает новые пустые поля и ведёт отдельный результат.

При ответе 4 на log₂8 программа показывает проверку обратным действием, 2⁴ = 16. Постороннего пояснения об инфляции в этой обратной связи нет.

В M24.6-A ответ 3 без выбора основания не принимается. Неверное основание отклоняется, верное основание вместе с правильным числом принимается. Исправленный после ошибки ответ C не получает статус первой успешной проверки.

В лабораториях проверены изменение числа групп, транспонирование таблицы 2 × 3 в 3 × 2, решение системы с результатом β = (4; 3), вырожденная система, запрет логарифма по основанию 1, изменение нормальной вероятности интервала при изменении стандартного отклонения, исходный режим знаковых перестановок, изменение ARI при изменении разбиения и запуск локального улучшения.

Для N(0,1) вероятность интервала [−1; 1] отображается как 0,682689; при стандартном отклонении 2 и тех же границах — 0,382925. В лаборатории показаны численные приближения, а не символически точные значения.

Все пять структурированных частей T41 выполнены через интерфейс. Произвольное заключение сохраняется в памяти страницы; явный экспорт создаёт текстовый файл с введённым текстом. Содержательная автоматическая оценка заключения не заявляется и не выполняется.

Поиск проверен с клавиатуры: Ctrl+K открывает диалог, Escape закрывает его. Визуально рассмотрены настольные и мобильные страницы, в том числе объяснение логарифма, транспонирование, нормальное распределение, итоговый проект и заполненный сеанс.

## Что эти проверки не подтверждают

Фактическая публикация в репозитории пользователя, сетевое кеширование GitHub Pages и поведение конкретного хостинга не проверялись. Safari, Firefox, реальные мобильные устройства и экранные дикторы не испытаны. Полное соответствие WCAG не заявляется.

Не проводились обучение реальных студентов, сравнение с контрольной группой, отсроченная проверка знаний или независимая внешняя экспертиза всего содержания. Наличие работоспособных лабораторий и проходящих тестов нельзя приравнивать к доказанной образовательной эффективности или профессиональной квалификации после прохождения курса.
